# Podcast Friend Starter Guide

A calm, plain-English manual for starting a small podcast or audio show — written for authors and one-person LLCs who already have a full life to run.

It covers the whole first-year arc, step by step, never condescending:

- **What to say before you buy anything** — the one-sentence promise, ten episodes on paper, and the three-episode rule before spending a dollar.
- **Bedroom recording on a budget** — a quiet, soft room and a phone beat a $400 microphone in a hard room.
- **Free editing and hosting, compared** — Audacity vs GarageBand vs the rest; free hosts compared; who really owns your RSS feed.
- **An episode structure you can sustain** — the five-part skeleton and batch habits that survive month three.
- **AI transcripts and show notes, with verification** — local-first transcription, a show-notes template, and a human-verification checklist that runs every time.
- **Guest etiquette** — invite, prep, consent, record, publish, thank-you, with email templates.
- **Consistency without burnout** — cadence you can keep, seasons, banked episodes, ADHD-friendly adaptations.
- **Quitting politely, if it stops being fun** — podfade versus a deliberate, kind goodbye.

Alongside the chapters: a **glossary** of every term of art, and four **worksheets** (show on a page, episode planner, gear budget, transcript verification checklist).

## Reading the guide

Two ways, both offline:

1. **The docs**: every chapter lives in [`docs/`](docs/) as plain Markdown. Read directly or in any Markdown viewer.
2. **The static site**: run the build (below), then open `site/index.html` in any browser. The site is a static build — no JavaScript, no analytics, no cookies, no accounts.

## Build and test

Local-first tooling: pure Python standard library. No installs, no network, no dependencies. Python 3.9+ (the repo is tested on 3.13).

```sh
./build.sh          # builds the static HTML site into site/
./test.sh           # runs the full test suite (52 tests)
```

Or the long way:

```sh
python3 scripts/build.py            # site build, with link/anchor validation
python3 -m unittest discover -s scripts/tests -v
```

The build self-validates: it refuses to finish if any internal link or `#anchor` in the generated site is broken, and exits non-zero.

## Utilities

```sh
python3 scripts/new_episode.py --title "My bedroom studio" --number 4
```

Creates `episodes/ep04-my-bedroom-studio.md` — a filled-in episode planner draft from `templates/episode-template.md` (the `episodes/` folder is git-ignored; those notes are yours).

## Design notes

- **Free tools first.** Every tool recommended in the guide is free or free-tier; gear is capped until the show has earned it.
- **Local-first.** Recording files, transcripts (local Whisper), worksheets, and the site build all stay on your own machine.
- **AI drafts, humans verify.** The guide's AI chapters include a mandatory verification checklist; nothing publishes unreviewed.
- **Tested build.** The site is generated by an Ordinary small Python script with real tests: renderer behavior, docs coverage of every goal topic, build validation, repo hygiene, and a secrets scan.

Complements the **audiobook-recording handbook** (the sibling manual about recording craft) and is part of the plain-English AI library published by **Asdale Dynamics, LLC** — see [dylanasdale.github.io](https://dylanasdale.github.io/) and *The Massive AI Manual*.
